# PBS Studio 界面设计

用户要求：整体重新设计，参考 iOS 与 AI 产品的质感，科技风；设计完成后直接实施。沿用材料、需求理解、PBS、导出的业务关系与专家协作方式。

后续明确约束：去掉宣传属性的文案和无实用意义的装饰，只保留操作、内容、状态与必要说明。首页不使用营销大标题、口号或装饰性大图。

## 视觉方向

采用银白工作台：冷灰背景、白色内容表面、石墨色主操作、冰蓝链接与焦点。相比全深色控制台，它更适合长时间阅读标书；相比大面积玻璃拟态，它能保持表格与原文的清晰度。半透明只用于顶栏和浮层，内容层保持实色。

参考 UI UX Pro Max 的 AI-Native UI、Minimalism & Swiss Style、keyboard focus modal 与 Vue 指南。其自动生成结果中的营销首页结构和紫色配色不适合本项目，不直接采用。来源：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill ，参考版本 `56ea9cf174ed86786187daa9de0e6247cb0747e4`。

## 设计规则

- 字体：系统 SF / PingFang SC / Microsoft YaHei，不引入远程字体；正文 14px，对话 15px，页面标题 20–24px，辅助文字不低于 12px。
- 色彩：正文 #20242c，辅助 #626b7a，背景 #f3f5f8，链接 #315fba；状态色仅表达实际语义，专家身份通过名字与头像同时辨认。
- 间距：4/8px 基础节奏；面板 24px 圆角、控件 10px 圆角、卡片 18px 圆角；边框与阴影保持轻量。
- 图标：统一线性 SVG，不使用 emoji 作为导航、附件与操作图标。
- 交互：保留可见键盘焦点，支持 reduced-motion；动画只用于短暂状态变化，不使用循环装饰动画。

## 页面与组件

1. 顶栏：品牌标记、项目/产品库胶囊导航、项目上下文；取消深蓝大色块。
2. 项目首页：标题与新建入口、真实项目卡片、清晰的阶段/材料/需求/PBS 计数与时间，保留删除确认。卡片通过独立链接进入，避免嵌套交互控件。
3. 双栏工作区：左侧专家对话、右侧成果画布；工作区内导航改为浮起的分段控件。窄屏支持对话/成果切换，避免两块挤压或超出视口。
4. 对话：简化顶部模型设置布局，统一专家身份样式，用户消息采用石墨色；两行输入区搭配独立附件和发送操作，保留 @ 专家。没有快捷建议或暂停按钮。
5. 材料：上传入口带统一图标，文件信息及背景说明清晰分层；支持键盘选择文件。
6. 需求/PBS/产品：保留有用的数据表，重做表头、行间距、标签、筛选和选中态。需求子视图使用明确的选中状态与计数。
7. 弹窗：简单编辑 560px、常规审阅 760px、复杂编辑 960px；最大宽度受视口限制。弹窗内部滚动，标题与操作区保持可见。阅读抽屉约 760px，复杂场景约 960px，窄屏适配。
8. 原生项目改名 prompt 替换为统一组件弹窗。业务确认与数据处理规则保持原样。
