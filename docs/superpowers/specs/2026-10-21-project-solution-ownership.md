# 客户解决方案归属修正

按用户补充的业务定义修正：解决方案针对具体客户需求，在项目内自由组合；产品库维护可复用的产品能力和产品BOM。

产品库移除方案页签、模板编辑、模板数据与导入类型。保留23个产品、23份BOM及独立数据包维护。数据包契约升级为schema 2，不允许包含方案；schema 1导入时忽略旧方案并提示。已有目录启动时迁移，旧版本记录和历史项目快照保留。

项目方案继续关联本项目需求、场景和PBS项，支持自由增删组合、命名和填写响应说明，不要求标准模板。两个客户可复用同一批产品、形成不同方案，方案编辑不会更改共享产品目录。

项目方案与快照逻辑从server/catalog.mjs拆到server/project-solutions.mjs。产品匹配提示词只接收当前客户需求和当前项目方案，不再注入全局方案模板。BOM仍由被选产品的组成展开，数量规则与版本保护保留。

既有项目中的自定义方案、产品关联和快照不删除；旧template_id不再参与当前项目视图和生成，重新保存方案时不再写入此字段。历史快照作为原始记录保留。

本修正取代2026-10-21-product-catalog-design.md中“共享方案模板”的设计部分。先前验证记录描述当时实现，当前维护约定以app/catalogs/README.md为准。

验证：ESLint与Vue模板编译通过，80项测试全部通过。新增用例覆盖产品包排除方案、旧目录迁移保留项目组合/快照、不同客户独立自由组合；模型生成检查确认不再接收全局方案模板。

临时演示库HTTP验证：schema 2、产品包无solutions字段，原客户项目1个方案与5个产品关联保留，当前项目视图无template_id，历史快照内容未改变。浏览器确认产品库仅有“产品目录、产品BOM、数据包维护”三个页签；项目编辑表单不再有模板选择，原组合正常保存，浏览器错误日志为空。
