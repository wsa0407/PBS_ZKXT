# 解决方案—产品—BOM 目录改造

> 后续修正：解决方案属于客户项目，已移除产品库方案模板。当前设计见 `2026-10-21-project-solution-ownership.md`，本文件保留此前设计/验证历史。

业务结构按用户明确的三层关系实施：解决方案响应标书/客户场景，产品组合实现解决方案，BOM描述产品组成。沿用已认可的 Workflow 主干；不增加 Skill 或多 Agent 运行时。

选用“独立版本化数据包＋通用校验/展开引擎＋项目引用快照”。只增加旧 seed 会使行业假设与业务代码继续耦合；引入完整 PLM 系统则超出 MOCK 演示范围。

低空包提供道路、森林、电力、测绘、防汛、应急六类模板，23个产品与23份BOM。公开参考设备来自 DJI、纵横官方资料；公司平台、自研原型、服务、接口工作包及全部方案组合和BOM明确为MOCK。厂商设备交付配置不冒充制造BOM。来源链接、核对日期、适配边界与待确认项保留在数据中。

产品来源与供给状态独立。外采、自研、服务均可保留产品编号并追溯BOM；原来的“非自有就清空product_ref”和“单位为套就自动计1”改为来源声明和显式数量策略。参考模板不自动成为客户确认方案；项目方案必须关联场景/需求和PBS项。

默认包只安装一次，旧ID与人工修改保留；未改动的旧模拟产品归档。数据包三方比较保留本地编辑，预览过期拒绝应用。方案和BOM编辑产生版本，目录保存全量修订。产品计量规则只绑定已声明的产品与参数，不推定覆盖半径、备机、算法准确率或接口人天。

项目保存包含目录修订、方案、产品、BOM、数量与输入摘要的快照；后续修改只标记待复核，不改变已存内容。BOM嵌套展开支持未知数量与可选项排除，并校验循环、悬空引用、单位一致性。跨方案共享PBS项只展示关联；唯一PBS清单支撑导出，避免共享项重复展开。

结构化页面维护方案、产品、BOM，JSON数据包承担批量维护和行业替换；Excel增加方案关系与BOM组成。旧PBS分类页继续保留作为采购分类视图，新的项目方案树补充业务结构，两种视图共用PBS产品项。

验收覆盖：默认安装幂等、旧数据保留、人工修改保护、引用/循环/数量校验、外采引用、专业数量策略、嵌套展开、历史快照、并发过期、真实Excel生成回读与页面交互。真实模型语义质量另需实际模型与业务材料评测。

维护合同与限制见 `app/catalogs/README.md`。当前是单目录和草稿流程；可选BOM项默认排除，未实现项目级配置器或正式方案审批，不能把模板和快照保存理解为方案批准。
