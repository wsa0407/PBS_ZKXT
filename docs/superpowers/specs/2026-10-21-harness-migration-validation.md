# PBS Harness 本地迁移验收

日期：2026-10-21。对应[架构设计](2026-10-21-deepseek-harness-migration-design.md)。

## 实际落地

- 保留现有 PBS 页面；聊天、材料分析、场景生成及 PBS 生成由官方 dsh 规划和调用业务工具。
- 运行时及 SDK 固定为 `0.2.1-rc.2`，不修改官方 Agent loop；通过发布包的 SDK profile、preset 和 MCP 扩展接入。显式绑定 PBS preset，确保身份指令与专属 Skills 真正加载。
- `agents/pbs/` 独立维护 AGENTS.md、三个 Skills、工具契约、preset 组合及合成评测材料，不依赖 Vue、SQLite 或 embedding 服务。
- `runtime/` 负责本地宿主、代理、MCP 传输及会话管理；`app/server/agent-adapter.mjs` 绑定本地证据、产品检索及业务持久化。
- 版本校验、引用校验、项目隔离、幂等、人工成果保护、数量规则继续由程序执行。模型提交业务草稿，人工确认通过可核对的操作卡片完成。
- 文档顺序读取与成果列表支持分页；PBS 分批合并保存，同名未人工处理草稿更新时保留 ID，其他批次保留。删除需另提人工变更。
- 停止时阻止后续写入，关闭运行时并等待在途工具结束后释放项目任务锁。保存运行状态、工具轨迹、模型用量、覆盖与会话身份，支持继续处理。

### 真实官方运行时

`node runtime/scripts/smoke.mjs` 通过：合成工具先返回片段移动错误，Agent 读取新 ID 后准确回答36个月；关闭进程后恢复相同会话，仍可回答已经读到的维护期限。

额外核验了持久日志中的 `agent-preset/selected=pbs` 和模型可见的 PBS 指令。SDK 的 `run().events` 仅包含 inbox receipt 后的活动片段，因此创建阶段的 preset 选择记录从持久日志核验。

### 完整合成业务案例

材料为园区巡查、异常通知、飞行记录、客户提供服务器、既有告警接口及验收后36个月维护。

真实运行使用 `deepseek-v4.1-flash` 经 BAI 接入官方 dsh；首次需求提交注入错误引用，工具拒绝后 Agent 修正。实际结果：

| 验收项 | 结果 |
| --- | --- |
| 原始需求 | 5条，原文引用全部通过核验 |
| 场景需求 | 3个，覆盖5条需求 |
| PBS草稿 | 8项，4项保留真实产品关联 |
| 项目解决方案 | 3个自由组合，未写入共享产品目录 |
| 材料覆盖 | 4个片段全部处理，无剩余或忽略 |
| 人工状态 | 未自动确认，项目未标记完成 |
| 数量 | 6项待估，保留36个月原文口径及单位待澄清事项 |

日志证实实际调用了 PBS Skills。保留产品关联可供页面继续展开产品 BOM；客户提供的服务器没有被自行添加为采购项。所有结果为待审草稿，此次验收不代表产品选型或报价已通过业务审核。

页面验收项目：`Harness架构验收`（`mvh0jr7enpjp`），位于本地预览数据库。原有怀柔项目继续保留。

### HTTP 和页面

- HTTP 立即停止任务：状态转为已取消，释放任务锁，聊天保留提示与继续按钮；启动阶段尚无会话 ID 时，继续原目标新建会话。
- 页面点击“停止处理”确实取消正在执行的任务；点击最新“继续未完成的工作”恢复**同一个持久会话**，完成只读核对。
- 恢复后仍为5条需求、3个场景、8项PBS，草稿未被只读核对改变。真实 token 用量记录到 `llm_calls`。
- 人工答复分析等辅助结构化分析边界也通过真实 dsh 调用验证，正确提取36个月并记录模型用量。

## 迁移边界与后续验收

- 公司工作台和公司 RAG 的实际接口尚未提供；本次交付契约与本地适配器。未来迁移需绑定兼容工具、模型、权限、证据身份和存储，并另外迁移项目数据与会话；不能仅复制提示词就保证无缝接入。
- 本轮完整真实模型业务验收使用合成材料。112页怀柔标书的完整重跑、成本、耗时与长任务预算仍需专项验收，没有把既有980条需求当作新 Harness 的性能通过证明。
- 旧模型分析函数保留供规则复用、兼容操作与回归测试；主要业务入口不再调用原固定 LLM 链。产品手册、客户答复、重匹配等辅助服务通过 dsh 的结构化提交边界执行；产品列表和 embedding 仍属于宿主服务。
- 官方版本为预发布版本。升级前需重跑工具纠错、preset/Skills 加载、会话恢复及业务契约验收。

## 重现

要求 Node ≥22.19，配置根目录 `.env`。密钥不进入 Agent 包或 Git。

```sh
npm ci --prefix runtime
npm ci --prefix app
npm run check --prefix app
node runtime/scripts/smoke.mjs
node app/scripts/verify-harness.mjs
npm start --prefix app
```

真实模型脚本会产生调用费用。业务脚本默认新建临时数据库；指定 `--db=/absolute/path.db` 时仅新增合成验收项目。
