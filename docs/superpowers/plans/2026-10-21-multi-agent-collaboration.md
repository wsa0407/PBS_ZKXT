# 三专家协作实施计划

基线：已获用户确认的三 Agent 设计；聊天视觉采用用户提供的群聊参考，专家名称、定向提问、右侧人工消息，长内容折叠。保留简短业务表达。

1. 新增可迁移角色与咨询工具契约；宿主按角色隔离 SDK 会话。
2. 持久化协作任务、激活队列、咨询、人工消息、交流事件与确认包；事务约束身份、版本、权限和写入屏障。
3. 接入阶段交接、异步咨询、暂停恢复和人工纠正；已有 HTTP 入口统一使用协作服务。
4. 聊天接入可恢复事件流，群聊样式、定向补充、运行中输入、明确确认范围。
5. 核心测试：人工交接、真实咨询关联、纠正竞态、恢复幂等和权限；小型真实模型及浏览器验收。

实施选择：首版调度器顺序激活三个独立持久会话（每角色最多一个激活），咨询工具立即返回并持久排队。这避免运行资源争抢，协议保留未来并行调度能力。
